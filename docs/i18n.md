# Система переводов (i18n)

Этот проект использует `next-intl` для интернационализации.

## Поддерживаемые языки

- 🇬🇧 Английский (en) - по умолчанию
- 🇷🇺 Русский (ru)

## Структура файлов переводов

```
messages/
├── en/
│   ├── index.ts          # Экспортирует все переводы для английского
│   └── home.json         # Переводы для главной страницы
└── ru/
    ├── index.ts          # Экспортирует все переводы для русского
    └── home.json         # Переводы для главной страницы
```

## Как добавить переводы для новой страницы

### 1. Создайте JSON файлы

Создайте файл переводов для каждого языка:

**messages/en/your-page.json**

```json
{
  "title": "Page Title",
  "description": "Page description",
  "section": {
    "heading": "Section Heading",
    "text": "Section text"
  }
}
```

**messages/ru/your-page.json**

```json
{
  "title": "Заголовок страницы",
  "description": "Описание страницы",
  "section": {
    "heading": "Заголовок секции",
    "text": "Текст секции"
  }
}
```

### 2. Добавьте импорт в index.ts

Обновите `messages/en/index.ts` и `messages/ru/index.ts`:

```typescript
import home from './home.json'
import yourPage from './your-page.json'

const messages = {
  home,
  yourPage,
}

export default messages
```

### 3. Используйте переводы в компоненте

**Серверные компоненты (по умолчанию в Next.js App Router):**

```tsx
import { getTranslations } from 'next-intl/server'

export default async function YourPage() {
  const t = await getTranslations('yourPage')

  return (
    <div>
      <h1>{t('title')}</h1>
      <p>{t('description')}</p>
      <section>
        <h2>{t('section.heading')}</h2>
        <p>{t('section.text')}</p>
      </section>
    </div>
  )
}
```

**Клиентские компоненты:**

```tsx
'use client'

import { useTranslations } from 'next-intl'

export function YourClientComponent() {
  const t = useTranslations('yourPage')

  return (
    <div>
      <h1>{t('title')}</h1>
    </div>
  )
}
```

## Переключение языка

Компонент `LocaleSwitcher` позволяет пользователям переключать язык.

Используется в навигации:

```tsx
import { LocaleSwitcher } from '@/components/locale-switcher'
import { getUserLocale } from '@/services/locale'

export default async function Layout() {
  const locale = await getUserLocale()

  return (
    <nav>
      <LocaleSwitcher currentLocale={locale} />
    </nav>
  )
}
```

## Добавление нового языка

1. Добавьте код языка в `src/i18n/config.ts`:

```typescript
export const locales = ['en', 'ru', 'de'] as const // добавили 'de'
```

2. Создайте директорию `messages/de/`

3. Создайте файл `messages/de/index.ts`:

```typescript
import home from './home.json'

const messages = {
  home,
}

export default messages
```

4. Создайте файлы переводов (например, `home.json`)

5. Обновите `LocaleSwitcher` компонент, добавив новый язык в массив `locales`

## Metadata для SEO

Для добавления переводов в metadata страницы:

```tsx
export async function generateMetadata() {
  const t = await getTranslations('yourPage')
  return {
    title: t('title'),
    description: t('description'),
  }
}
```

## Советы

- Используйте вложенные объекты для группировки связанных переводов
- Называйте ключи описательно (например, `hero.title` вместо `title1`)
- Проверяйте, что все ключи одинаковы во всех языковых файлах
- Используйте TypeScript для автодополнения ключей переводов
